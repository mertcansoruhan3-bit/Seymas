# ŞEYMAŞ OFİS – Ticari Yönetim v2

Android Studio projesidir. Şeymaş Kapı – Erzurum için hazırlanmıştır.

## İçerik
- Ticari ana panel: ciro, alacak, net kasa, gider
- Müşteri kayıtları: telefon, adres, vergi no, not
- Çelik kapı / bina giriş siparişleri
- En, yükseklik, kasa, açılış yönü, kilit, malzeme/model
- Fiyat, kapora, kalan otomatik gösterim
- Sipariş durumları ve notlar
- Cari / müşteri borç takibi
- Tahsilat ve kısmi ödeme
- Ödeme yöntemi ve açıklaması
- Kasa ve gider takibi
- Rapor ekranı
- İnternetsiz yerel SQLite veritabanı

## Açma
Android Studio → Open → bu klasörü seç → Gradle Sync → Run.

Not: Bu paket APK değil, Android Studio kaynak proje ZIP'idir.
